## 🏠🔑  Description

In this project we create a set of data with the objective to later on develop a machine learning model to make price predictions on real estate sales in Belgium. For this purpose, we then extract and clean the data of various properties to sell and rent (for this educational purpose only). Finally, we save the data.

## 🏡🔨  Usage

1. Clone the repository to your local machine.

2 .To run the script, you can execute the `info_per_property.py` file 

3. The script retrieves 18 key pieces of information for around 1000 properties in Belgium the saves them in a csv file.
